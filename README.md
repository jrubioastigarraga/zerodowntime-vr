# Uhin Apps · Zero-downtime — prototipo inmersiboa

Web aplikazio baten hedapena produkzio-zerbitzarian eta gorabehera baten kudeaketa
(502 errorea + TLS ziurtagiri iraungia) simulatzen dituen 360°/WebXR eszena.

- **Simulazioa:** [`vr/`](vr/) — Three.js + WebXR, nabigatzailean edo VR betaurrekoetan.
- **Gidoia:** [`01_gidoia_zero_downtime.html`](01_gidoia_zero_downtime.html).
- **Foro-sarrera:** [`02_foro_sarrera.html`](02_foro_sarrera.html).

## Nola erabili

- Ordenagailua: WASD edo eskuin-botoia mugitzeko; klik objektuetan; klik bikoitza lurrean joateko.
- Mugikorra: ukitu eta bi hatzekin mugitu.
- VR: «VR-n sartu» eta kontroladorearen katua.
- Interneteko konexioa behar da (Three.js CDN bidez kargatzen da).

## Egitekoa

Ticket-a irakurri → USB tokena hartu → hiru komandoak exekutatu → R1 rack-a ireki →
blade-a hedatu → karga-balantzea aktibatu → bezeroa egiaztatu → gorabehera diagnostikatu →
ziurtagiria berritu → post-mortema sinatu.
